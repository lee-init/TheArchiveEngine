# The Archive Engine

Attempting to create a game engine and a game to go along with it

## Build

1. Open a cmd prompt and run setup.bat. This updates the PATH variable so the VisualStudio compiler (cl) can be located
2. Run build.bat. This compiles the translation units (.cpp file) into objects (.obj) and links those object to create a .exe file
3. Run win32_game.exe. At

### Note: Running setup.bat is not permanent. If you close command prompt you will need to run setup.bat again
